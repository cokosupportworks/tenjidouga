はじめて使う

展示動画プレイヤーは、端末に登録した動画をサムネイルから選んで上映するWebアプリです。サムネイルは動画を選ぶ小さな画像です。会場で使う前に、使用する端末とブラウザで動画を登録し、再生と音を確かめてください。

アプリを開いて動画を登録する

  1. オンラインの状態で、配布されたアプリのURLを開きます。iPad・iPhoneはSafari、WindowsはEdge、Macは使用予定のブラウザで開きます。
  2. 歯車の設定を開き、動画 → ＋ 動画を追加を押します。iPad・iPhoneでは選択画面の「写真」や「ファイル」から、Mac・Windowsではファイル選択画面から動画を選びます。複数選択できます。
  3. 端末に保存した件数が表示されたら設定を閉じ、見たいサムネイルを押します。別のサムネイルを押すと、その動画や再生区間に切り替わります。帯は横、グリッドは必要に応じて縦にスクロールできます。

再生位置のバーを操作すると任意の位置へ移動できます。設定ウィンドウは上の見出しをドラッグして移動できます。端に寄せても、つかみ直せる部分が残ります。

オフラインで使う

  1. 同じ端末・ブラウザでオンラインのうちに開き、設定の「動画」にオフラインで起動できますと表示されるまで待ちます。iPad・iPhoneでホーム画面から使うなら、Safariの共有メニューから「ホーム画面に追加」を選び、追加したアイコンから開いて素材を登録してください。
  2. 本番前に通信を切り、使う入口から開き直して、登録した動画が再生できるか確認します。無線ミラーリングを使う本番では、受信機と通信するWi-Fiも確認してください。

動画と設定は使用したブラウザ側に保存されます。Safariとホーム画面から開くWebアプリで一覧が異なる場合は、上映に使う方で登録します。クラウド上にだけある動画は、取り込む前に端末へダウンロードします。

アプリから説明書を開く

設定 → 説明書 → HTML版の説明書を開くを押すと、別のタブで開きます。オフラインの準備が済んだ更新版では、説明書も端末から読めます。

動画と再生区間を編集する

設定 → 動画で登録した動画名を押すと、プレビューと編集欄が開きます。動画ファイルは一度登録すれば、その中から複数の区間を作れます。

サムネイルと表示名を変える

プレビューの位置を合わせて動画全体のサムネイルに使うを押します。動画全体の表示名を入力し、左寄せ・中央寄せ・右寄せから選びます。表示名を空欄にするとファイル名が表示されます。再生音量は動画ごとに調整できます。

再生区間を決める

  1. ＋ 区間を追加を押します。開始時刻・終了時刻を「分:秒」または秒数で入力します。たとえば「3:30」から「9:00」です。
  2. 映像に合わせて決めるには、プレビューのバーや5秒・1コマのボタンで位置を合わせ、開始・終了それぞれのプレビュー位置を使うを押します。この区間を試聴で映像と音を確認します。
  3. 区間の表示名を入力します。開始時刻の画像を使うか、プレビューで画像を選びます。区間を保存を押します。別の区間を追加する場合も同じ操作です。

色付き部分を押すと、その区間の開始位置にプレビューが移動します。コマ送りはブラウザが取得した映像のフレーム間隔を使うため、素材や端末によって刻みが異なることがあります。

区間ごとの上映とカット版

区間のサムネイルで、区間ごとに表示、1枚にまとめる、または両方を選べます。1枚にまとめると、区間一覧の上から順に再生し、区間間の映像を飛ばします。↑・↓で区間の再生順を変えられます。

動画全体のサムネイルも表示をオフにすると、作った区間だけを並べられます。設定の動画ページにあるサムネイルの表示順で、1枚ずつ並びを変えられます。区間ごとの上映は指定の終了時刻で停止します。

画面の配置を調整する

設定 → レイアウトでは、プレビューを見ながら、1画面と2画面上映の操作側を別々に設定できます。テレビ側の上映専用画面は、動画を映すための画面です。

1画面で使う

編集する画面 → 1画面を選びます。動画枠の幅・高さ・横位置、上部の余白、サムネイル帯の高さや幅を調整できます。サムネイル帯の間隔は均等、または個別に設定できます。2本ずつまとめたいときは、グループが切り替わるサムネイルの手前の間隔だけ広げます。

拡張画面を使うときの操作側

編集する画面 → 2画面上映の操作側を選び、帯状またはグリッドを選択します。自動列数では4本は2×2、2本は横に2枚です。列数と間隔は手動でも調整できます。再生ボタンとシークバーは上・下を選べ、まとめて非表示にできます。

2画面の操作側で設定ボタンも隠した場合は、キーボードの S で設定を開きます。キーボードなしで運用する端末では、設定ボタンを表示しておくとタップで再設定できます。

テキスト・図形・画像を置く

  1. 設定 → 表示要素でテキスト、四角、円、画像を選び、＋ 追加を押します。
  2. 追加した要素をプレビューでドラッグするか、横位置・縦位置・サイズをスライダー、数値、±ボタンで調整します。テキストはボックスの幅と色も変えられます。
  3. 一覧で要素ごとの表示・非表示や重なり順を変更できます。2画面上映中の表示要素は操作側に置かれます。

テレビ・プロジェクタ接続とiPad

会場でどちらの映し方を使うか

映し方手元の画面客席の画面
ミラーリング（複製）通常の再生画面手元と同じ画面。サムネイルや開いた設定も映ります。
拡張・2画面上映操作画面。サムネイルや再生操作上映専用ウィンドウ。全画面にすると動画だけ映ります。

まずテレビやプロジェクタをオンにし、使うHDMI入力を選びます。端末の端子に合う映像出力対応のケーブルやアダプタでつなぎます。画像と音を両方送る場合はHDMIを使い、プロジェクタにスピーカーがない場合は別の音の出し方を確認します。ミラーリングのときは、作品の準備や設定を先に済ませておくと客席に操作を映さずに済みます。

iPadで画面全体をミラーリングする

有線の場合は、対応するUSB-CまたはLightning用の映像アダプタとHDMIケーブルを接続します。画面が拡張される機種では、iPadのディスプレイ設定でミラーリングを選びます。無線の場合は、AirPlay対応の受信機と同じWi-Fiに接続し、画面右上から下にスワイプして画面ミラーリングを選びます。受信機名をタップします。

iPadで上映画面だけを外部へ送る

外部画面へアプリのウィンドウを移動できるiPadと、対応する有線接続が必要です。例として、iPad Air第5世代、iPad Pro 11インチ第3世代、iPad Pro 12.9インチ第5世代があります。iPadOSの版によって対応機種が異なるため、下のAppleの一覧で確認してください。

  1. iPadの設定 → マルチタスクとジェスチャでステージマネージャを選び、外部画面を接続します。SafariでアプリのURLを開きます。
  2. アプリの設定 → 2画面上映 → 上映画面を別のディスプレイに全画面表示するを押します。上映ページがタブで開いたら、Safariの別ウィンドウに分けます。
  3. 上映側のウィンドウの上部にあるウィンドウコントロールでディスプレイに移動を選ぶか、マウスなどのポインタで外部画面へドラッグします。外部画面で全画面を押すか、iPadOSのウィンドウコントロールで全画面にします。元のSafariウィンドウで再生します。

iPadのボタンは上映ページを開くところまで行います。移動と全画面化はiPadOSの操作です。外部画面へウィンドウを移動できないiPadではミラーリングを使います。

iPhone・Macで映す

iPhoneでミラーリングする

  1. 有線の場合は、iPhoneの端子に合う映像出力対応のUSB-CまたはLightning用HDMIアダプタを使います。テレビで使ったHDMI入力を選びます。
  2. 無線の場合は、iPhoneとAirPlay対応テレビ・Apple TVなどを同じWi-Fiに接続します。コントロールセンターの画面ミラーリングから受信機を選びます。Face ID搭載機種では画面右上から下に、ホームボタン搭載機種では画面下から上にスワイプします。
  3. アプリを横向きで開き、サムネイルを選びます。無線を終えるときは、コントロールセンターの画面ミラーリング → ミラーリングを停止を選びます。

このアプリのiPhone版はミラーリングで上映します。iPhone側にサムネイルを残したままテレビへ動画だけを出す2画面操作には、対応iPad、Mac、またはWindowsを使います。

Apple：iPhoneの有線接続Apple：iPhoneの画面ミラーリング

Macで画面全体をミラーリングする

HDMIまたは映像出力対応のUSB-Cアダプタでつなぎ、アップルメニュー → システム設定 → ディスプレイを開きます。外部画面を選び、使用形態でミラーリングを選びます。対応する受信機を使う場合は、コントロールセンターの画面ミラーリングから選ぶ方法もあります。

Macで上映画面だけを外部へ送る

  1. システム設定 → ディスプレイ → 使用形態で拡張ディスプレイを選びます。マウスがどの方向に外部画面へ移るかは「配置」で確認します。
  2. アプリの設定 → 2画面上映 → 上映画面を開くを押します。別ウィンドウの上端をドラッグし、外部ディスプレイに移します。
  3. 外部画面の上映ウィンドウで全画面を押し、手元の操作画面のサムネイルを選びます。終了時は全画面を解除し、設定で上映画面を閉じるを押します。

Macが対応する外部画面の台数や接続方式は機種によって異なります。テレビで音を出すときは、システム設定のサウンド → 出力でHDMI機器を選びます。

Apple：Macの拡張とミラーリングApple：MacのHDMIと音声

Windows・タブレットPCで映す

Windowsで同じ画面を映す

HDMIでつないだら Windowsキー＋P → 複製を選び、通常の再生画面で上映します。キーボードがないタブレットPCでは、スタート → 設定 → システム → ディスプレイで複数のディスプレイの表示方法を変更します。

Windowsで上映画面だけを外部へ送る

  1. Windowsキー＋P → 拡張を選びます。キーボードがなければ、ディスプレイ設定で表示画面を拡張するに相当する選択肢を選びます。
  2. アプリを開きます。設定 → 2画面上映 → 上映画面を別のディスプレイに全画面表示するを押し、ウィンドウ管理の許可を求められたら許可します。
  3. Edgeが追加操作を求めた場合は、タブレット側に開いた上映ウィンドウのテレビに全画面表示を押します。上映後は設定の上映画面をこの画面に戻すを押すと、全画面を解除して操作側へ戻ります。

手動で移動する場合は上映画面を開くを押します。上映ウィンドウの上端をドラッグするか、そのウィンドウを選んで Windowsキー＋Shift＋←／→ を押します。テレビ側で全画面を押します。拡張にはPCと接続機器の対応が必要です。自動配置にはブラウザの画面管理機能とサイトの許可も必要です。

上映前に確認すること

症状確認すること
テレビに何も映らない電源と入力番号、ケーブル、OSの画面検出を確認。拡張の場合は上映ウィンドウの移動先も確認します。
テレビに操作まで映るOSが複製・ミラーリングになっていないか確認し、拡張に変更して上映専用ウィンドウを移します。
映像は出るが音が出ない動画の再生音量と、テレビ・プロジェクタの音量を確認。Windowsは「設定 → システム → サウンド → 出力」でHDMIを選びます。
上映ウィンドウが開かない公開URLで開き、ブラウザのポップアップ設定を確認。iPadではSafariの操作ウィンドウから開いてください。
動画や設定が見つからない前回と同じURL・ブラウザ・入口から開きます。サイトデータを消すと、保存済み動画や設定が失われます。
